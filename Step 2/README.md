## 🔄 ניהול טרנזקציות – COMMIT & ROLLBACK

בוצעו פעולות לניהול טרנזקציות:

- ROLLBACK – ביטול שינויים והחזרת בסיס הנתונים למצב קודם  
- COMMIT – שמירת שינויים באופן קבוע  

פעולות אלו מדגימות שליטה בתהליכי עדכון הנתונים.
